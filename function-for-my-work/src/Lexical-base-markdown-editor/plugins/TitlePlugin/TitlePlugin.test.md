# TitlePlugin Protection Test Guide

## 测试增强的H1标题保护功能

当 `hasDefaultTitle={true}` 时，第一个H1标题应该在任何情况下都不能被删除。

### 测试场景

#### 1. 基本删除测试
- [ ] 在H1标题开头按 `Backspace` - 应该被阻止
- [ ] 在H1标题开头按 `Delete` - 应该保持H1结构
- [ ] 选中整个H1内容按 `Backspace` - 应该被阻止
- [ ] 选中整个H1内容按 `Delete` - 应该被阻止

#### 2. 高级删除测试
- [ ] 使用 `Ctrl+A` 全选后按 `Delete` - H1应该保留
- [ ] 使用 `Ctrl+Backspace` 删除单词 - 涉及H1时应该被阻止
- [ ] 使用 `Shift+Delete` 删除行 - 涉及H1时应该被阻止
- [ ] 多选（从H1开始到其他段落）删除 - 应该被阻止

#### 3. 剪切和粘贴测试
- [ ] 选中H1内容执行剪切 `Ctrl+X` - H1结构应该保持
- [ ] 在H1位置粘贴其他内容 - H1应该保留

#### 4. 键盘快捷键测试
- [ ] `Ctrl+A` + `Delete` - H1应该保留
- [ ] `Ctrl+A` + `Backspace` - H1应该保留
- [ ] `Ctrl+A` + 输入新内容 - H1应该保留

#### 5. 边界情况测试
- [ ] 空的H1标题删除测试 - H1节点应该保持
- [ ] 只有一个字符的H1删除 - H1节点应该保持
- [ ] 从其他段落向上删除到H1 - H1应该保持

### 预期行为

✅ **正确行为**：
- H1标题节点始终存在
- 可以编辑H1内容，但不能删除H1节点本身
- 显示占位文本当H1为空时
- 其他段落正常可以删除

❌ **错误行为**：
- H1标题完全消失
- 编辑器开头不是H1标题
- 无法阻止H1删除操作

### 自动恢复机制

插件包含以下保护机制：
1. **实时命令拦截** - 拦截所有删除相关命令
2. **状态监听器** - 监听编辑器状态变化
3. **定时检查** - 每500ms检查H1是否存在
4. **立即恢复** - 检测到H1丢失时立即恢复

### 调试提示

如果保护功能不工作，检查：
1. `hasDefaultTitle` 是否设置为 `true`
2. CSS样式是否正确加载
3. 浏览器控制台是否有错误
4. Lexical版本是否兼容

### 测试命令优先级

所有保护命令都使用 `COMMAND_PRIORITY_HIGH` 确保优先执行。
